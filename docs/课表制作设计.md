# 课表制作 · 设计规格（2026-11-13 定稿）

> 下一阶段功能。把排课表的课**自动排进「周几·上午/下午·教室」**，画成上/下半两张课表，可拖拉微调、存档、列印。
> 时段/教室在此功能前「不归 BA 系统管」；本功能把它们请进系统。
> 规则经 Aj. Tsai 逐条确认。

## 1. 它是什么
新分页「课表制作」：
选学期 → **⚡一键自动排** → **上/下半两张网格**（周几 × 上午/下午 × 教室）→ 冲突/超容量/超门数/超学分 **即时标红** + 侧栏列问题 → **手动拖课片微调**（即时重算）→ **💾存档** + **🖨️列印**。
> 本质是一个**排课求解器**：不保证完美解；排不下的**留空标红**让人手动，不硬塞、不假装排好。

## 2. 权限
- **能排 / 存 / 列印**：Head of Administration（角色码 `teacher`）＋ Admin。
- **只读看 + 列印**：Director / pic / 其他。
> 与「秘书处对账」一致由少数人掌控；秘书处正是排教室的人。

## 3. 资料面
### 3.1 课来源（已有，排课表 `schD`，该学期）
每门：`course`(课程码) / `cc`[{cohort,count}](届别+各届人数) / `cls`(班级) / 人数(=cc 各 count 总和) / `tc`(老师) / `half`(上下半，可能空/全学期) / **Capstone = `type==='Capstone'`**（已确认，见 index.html `schD.filter(r=>r.type==='Capstone')`）/ 学分(查 catalog.credit by course) / **`nt`(备注)——可能写排课的特殊要求，当约束读，见 §5.5**。

### 3.3 上下半时间点（后台操作设定，Aj. Tsai 填）
每学期：上半起迄、下半起迄（日期）。用于课表抬头标示。**时段本身固定两段**（见 §4），这里只是日期区间。
### 3.4 CD 专业 / LA·KH 识别（查 `catalog`，匿名可读）
- **CD = 创意设计专业**（`depts.code='CD'`）。CD 专业科目 = `catalog.dept='CD'` 的 `course`。
- **LA/KH** 是跨专业语言/层级课（LA160 基础英语、LA161 交际英语1…；KH351–355 一串层级）。**层级** = 同字母前缀 + 数字递增。
### 3.5 排好的结果（**新表 `timetable`**，可列印）
每门课（该学期）→ `{half(上/下), day(周一~周六), slot(am/pm), room(教室code)}`。存起来、重开可续排、可列印。

## 4. 时段模型
- 周一~周五 × { `am` 09:00–12:00、`pm` 13:30–16:30 } = 每半 **10 格**。
- **Capstone 例外**：下半 · **周五 + 周六** · am+pm（占 4 格）。**周六只给 Capstone**。

## 5. 排课规则
### 5.1 硬约束（违反标红，不硬塞）
1. 教室容量 `cap` ≥ 课人数。
2. 一时段一教室一门课。
3. 一时段一**老师**不排两门（老师不撞堂）。
4. 一时段一**届别**不排两门（按 cc 每个 cohort；届别不撞堂）。
5. **Capstone** → 下半 · 周五/周六 · am+pm。
6. **老师每半 ≤ 4 门**。
7. **届别每半 4+3 或 3+4**（每届别上/下半门数为 {4,3} 或 {3,4}）；**有 Capstone 则该届别总门数 ≤ 6**。
8. **届别每学期总学分 ≤ 21**（学分=`catalog.credit`；Capstone=6 学分）。
### 5.2 软优先（尽量满足，冲突可让）
- **321/322 优先给 CD 专业课**（`pref_dept` 匹配课的 dept）。
- **LA/KH 层级排序**：同学期开了**连续两级**（如 LA130&LA131、LA131&LA132、KH351&KH352…）→ **低级排上半、高级排下半**（先修低级）；单开一门不强制。
### 5.3 上下半分配
- 排课表**已填 `half`（上/下）的 → 钉死，照用**。
- `half` 空/全学期的 → **系统自动分**（满足约束 6/7/8 + LA·KH 排序）。
- 系统**可在可行时把未钉死的课在上/下半间挪动**，以解掉冲突、配平门数/学分（Aj. Tsai 确认可调）。
### 5.4 求解策略
贪心 + 回溯/局部搜索皆可；目标：满足全部硬约束，软优先尽量。**排不下的留空标红**，列侧栏让人手动拖。

### 5.5 备注（`nt`）当约束读（Aj. Tsai 确认）
排课记录的**备注里常写排课的特殊要求，要当约束遵守，不能忽略**（例：固定某时段/星期、指定某教室、合班、要大教室或视听设备等）。
- 备注是**自由文字**，实作时**先从实际资料捞一批 `nt` 样本**（`sget('schedule?select=note&sem=eq.<学期>')` 或排课表现成 `schD` 的 `nt`），归纳出能自动遵守的类型（如「周三」「下午」「X教室」「合班」关键词），把这些变成排课时的额外约束。
- **抓不出规则的随意备注**：不猜、不乱排 → 把该门课连同原始备注**列到侧栏「备注待人工」**，让排的人自己照办。
- 备注原文也要能在课表/格子看到（别弄丢），方便人工核对。
> ⚠ 开工后请 Aj. Tsai 给几个真实备注例子，好把「能自动遵守的类型」定准。

## 6. 画面 / 交互
- 新分页「课表制作」（`data-tab` 与放哪组、分页名字待定），权限见 §2。
- 选学期 → ⚡一键自动排 → 两张网格（上半/下半）。建议：**行=教室、列=周几×am/pm**；每格课片=课码·届别·人数·老师；Capstone 片跨周五六。
- **标红**：超容量/撞堂/超门数/超学分/未排进去的。侧栏「待处理 N」列未排 + 冲突。
- **拖课片**到别格 → 即时重算该格与相关约束。
- **💾存档**（写 `timetable` 表，走验 PIN 的 security-definer RPC，同对账）；**🖨️列印**（上/下半各一张 A4，抬头带上下半时间点）。

## 8. 现有可复用的模式（建时参考）
- **分页/面板**：`tabs` 的 `data-tab` + `switchTab(id)` + `panel-<id>`；`applyRoleVisibility` 控角色。**刚做的「秘书处对账」(§RECO 区块 + `panel-reco` + `renderRecoPanel`) 是最接近的样板，照抄结构。**
- **Supabase 读写**：`gasGet(action)` 加读、`gasPost(action)`→`srpc(fn,b)` 加写（都在文件末尾 Supabase IIFE 内；007 的 `schedLock`/`setBaseline`/`ackRow` 是范例）。
- **后台操作 ref 表增删改**：教室库照 `catalog`/`depts`/职位那套（后台分页 + 卡片/弹窗编辑）。
- **catalog 读**：`sget('catalog?select=dept,code,zh,credit,...')`（匿名可读，取学分/CD/LA/KH）。
- **⚠ onclick 带参一律用 `jsq()` + 转义单引号，不要用 `JSON.stringify`**（会双引号打架、onclick 失效；对账踩过）。
- **列印**：`printPanel`/`@media print`/`body.print-<x>`；或自建（参考 `recoPrint`）。
- **测试**：`node tools/ui_smoke.mjs`（本地/`--url` 线上）；`web-design-rules` skill（375px 溢出、部署比对 hash）。
