# 课表制作 · 功能主旨

> 最后更新：2026-11-16（加「🧩 只补排」、双向同步、排课要求栏位）
>
> 一句话：**把「排课表」里一学期的课，自动排进「周几 · 时段 · 教室」，画成课表，可微调、存档、列印。**
> 本质是一个**排课求解器**——不保证完美解；排不下的留空标红，交给人处理，不硬塞、不假装排好。

---

## 为什么要有它

以前「哪门课在周几哪个时段、用哪间教室」**不归 BA 系统管**，由秘书处手工排、手工画。课一多就容易撞堂、超容量、漏排，改一次全部重来。
课表制作把**时段和教室请进系统**，让系统按规则自动排、即时抓冲突，人只做微调和拍板。

---

## 它做什么（一条龙）

1. **选学年学期** → 系统读该学期的排课表。
2. **⚡ 一键自动排** → 把课排进「周几 · 上午/下午 · 教室」，画成上/下半两张课表。
3. **即时标红 + 待处理一览** → 撞堂、超容量当场标红；排不下、只排到一节、要人看的备注，都列出来。**每门未排课下面有 💡 建议**（改到哪半 / 换教室 / 拆成几班各几人）。
4. **手动微调** → 拖课片换时段/教室、点课片改老师、改半方案、还原/重做。
5. **💾 存档 + 🖨️ 导出/列印** → 存进数据库；列印成 A4 课表（依教室号/届别/老师三种检视）。

---

## 遵守的排课规则（摘要）

> 详细说明在系统里的「**ℹ️ 排课规则**」弹窗（所有角色都看得到），这里只列骨架。

- **🔴 硬约束**（违反标红，必须解决）：容量够、一时段一教室一门课、老师不撞堂、届别不撞堂。
- **🟠 软提醒**（排不下可勾「已核对」放行）：老师每半≤4 门、届别上下半 4+3 或 3+4、届别学分≤21、两节尽量不同天。
- **🟡 软优先**（尽量，冲突可让）：321/322 优先给 CD、LA/KH 层级先修低的、教室挑刚好够大。
- **⚙️ 特殊规则**：Capstone 排周末三时段、同老师固定教室；合班当一门；个别学生（届别只 1 人）不挡排课；专用教室（电脑室）照排课要求；**排课要求**（指定教室／限定星期／连续两天／合班）在排课表新增、编辑课程时用栏位填，旧备注的文字写法仍照办。
- **📋 排课先后**：越难安排的越先排——届别越多先排、越抢手先排、Capstone 大班先排；试多种顺序取未排最少的一版。

## 谁能用

| 角色 | 能做什么 |
|---|---|
| **Head of Administration（秘书处）、管理员** | 排 / 微调 / 存档 / 列印 |
| **主任（director）、其他** | 只读看 + 列印（主任另可透过撞课清单的「改 课码」去改排课表） |

---

## 和排课表的关系（关键）

**排课表是来源，课表制作是据它排好、再存档的结果——排课表改了不会自动更新。**
主任等人在排课表调动后，课表制作顶部会出现橘色「可能过时」提示。要更新，由秘书处或管理员二选一：

- **🅰 🧩 只补排**（推荐）：已排好的课留在原位（手动调过的也保留），只排**新增**的、原本没排上的、以及改了老师/届别/人数后**原位放不下**的课；排课表删掉的课从课表拿掉。排完上方绿色框列出动了哪几门 → 核对 → 存档。也可以自己拖。
- **🅱 整张重排**：按「⚡ 整张重排」，以最新排课表重算整张，但**不保留**手动微调过的教室/时段 → 存档。

- **老师、上下半**两边都能改 → 橘色框里逐门选「← 照排课表」或「写回排课表 →」，系统不替人决定方向。

> **排课表那一页也会提示**：所选学期的课表存档跟排课表不一样时，筛选栏上方出现「📋 课表制作还没跟上」横幅，可一键前往。
> 橘色提示随时比对（不只看存档时）：课程／老师／届别／人数／上下半／备注，或新增、删除，有任何不一样就出现。
> 排课表**新增**的课，手动拖不到，要按 🧩 只补排（或 🅱 整张重排）才会排进来。
> 工具列上「🏅 前三名」「🧩 只补排」收在「⚡ 一键自动排」右边的 ▾ 里；有课可以只补排时 ▾ 上有橘点。

---

## 边界（不做什么 / 要人处理）

- **排不下的不硬塞**：留空标红、列进「待处理一览」，让人拖或调上下半（🔀 改半方案）。
- **实习课不排进课表**（本来就不占教室时段）。
- **软提醒解不掉时**由人勾「已核对」放行（例如很多届别本来就 24/27 学分，超过 21 是常态）。
- **时段/教室的日期、教室库**由管理员在后台设定。
- **人数超过教室容量**（排不进任何教室、或超过备注指定的教室）：建议里直接算「**拆成 N 班各约 M 人**」，由人拆班或换更大教室。

---

## 系统内建的帮助（工具列，所有角色可见）

- **🧭 使用引导** — 一页 7 步：选学期 → ⚡ 一键自动排 → 看待处理一览 → 微调 → 存档 → 导出列印 → 排课表改了怎么更新。**新同事先看这个。**
- **ℹ️ 排课规则** — 「一键自动排」按什么排：🔴 硬约束 / 🟠 软提醒 / 🟡 软优先 / ⚙️ 特殊规则 / 📋 排课先后，末尾附「排课表改了怎么更新（🅰/🅱）」。
- **待处理一览的 💡 建议** — 每门排不上的课，当场给可操作的建议（改半 / 换教室 / 拆班 / 加一节）。
