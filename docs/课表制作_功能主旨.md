# 课表制作 · 功能主旨

> 最后更新：2026-11-18（加：草稿／定版与旧版、排课表填课时的两个提示；「合班」全站拿掉）
>
> 一句话：**把「排课表」里一学期的课，自动排进「周几 · 时段 · 教室」，画成课表，可微调、存档、定版、列印。**
> 本质是一个**排课求解器**——不保证完美解；排不下的留空标红，交给人处理，不硬塞、不假装排好。

---

## 为什么要有它

以前「哪门课在周几哪个时段、用哪间教室」**不归 BA 系统管**，由秘书处手工排、手工画。课一多就容易撞堂、超容量、漏排，改一次全部重来。
课表制作把**时段和教室请进系统**，让系统按规则自动排、即时抓冲突，人只做微调和拍板。

---

## 分工（最重要的一张表）

| | 排课表 | 课表制作 |
|---|---|---|
| 管什么 | 上什么课：课程、老师、届别、人数、上下半、备注／排课要求 | 什么时候、在哪间教室：周几、时段、教室 |
| 谁在改 | 主任 | 秘书处（Head of Administration）、管理员 |

**系统负责排和提醒，人负责挑和拍板。** 老师、上下半两边都能改，对不上时系统不替人决定，只把差异列出来。

---

## 它做什么（一条龙）

0. **（在排课表）主任填课时就有提示** → 选好届别，表单里直接显示「🗓 照现在的课表试排」（拿课表存档实际试：不用动／排得进并列出位置／改到另一半就排得进／排不进与卡在谁）、「📊 这门课放哪一半比较排得上」（按门数估，上半／下半各标 🟢🟡🟠🔴）；格子不够（某届别或老师那一半超过一周 10 格）时出现黄色「⚠ 格子不够提醒」。只提醒，不挡储存。
1. **选学年学期** → 系统读该学期的排课表。
2. **⚡ 一键自动排** → 把课排进「周几 · 上午/下午 · 教室」，画成上/下半两张课表。旁边的 ▾ 里还有「🏅 前三名」（比较没排上／只排 1 节／两节同一天／个别学生撞课，自己挑）、「🧩 只补排」。
3. **即时标红 + 待处理一览** → 撞堂、超容量当场标红；排不下、只排到一节、要人看的备注，都列出来。**排不好的课都有 💡 建议**：没排上／只排 1 节（改到哪半、被哪门课挡住、换教室、拆成几班）、两节同一天、没排到连续两天（其他时段被谁挡住、挡路的课能不能挪、改到另一半试排）、个别学生撞课（两门课各自可以挪去哪、挪过去还撞几组）、撞堂／超容量（挪去哪或换哪间教室）。建议窗里的课码、届别、老师**都能点，跳到排课表**。主任看存档时也看得到；建议只是给人看，不会动课表。
4. **手动微调** → 拖课片换时段/教室、点课片改老师、改半方案、还原/重做。
5. **💾 存档 → ✅ 定版** → 存档存下来的是**草稿**；全部排好后按「定版」，才是正式课表。
6. **📤 导出／列印** → Excel 或 A4 课表（依教室号/届别/老师三种检视）；另有「📅 上课日期」表。

---

## 画面从上到下（2026-11-18 简化后）

学期选单 → 工具列（⚡ 一键自动排 ▾｜💾 存档／✅ 定版｜📤 导出／列印｜更多 ▾｜⚙️ 选项 ▾｜ℹ️ 说明 ▾）→ 日期与检视切换 → 待处理一览 → 课表。

- **没事就不占位置**：全部正常时不显示「课表检查」；已定版时不显示说明条；Capstone 只有排到周一～周四或周日才提醒（列出是哪几门）；实习课是一行小字。
- **有事才出现**：橘色框（跟排课表不一样）、草稿说明、课表检查（撞堂／同时段多门／两节同天）、绿色框（只补排的结果）。
- **「更多 ▾」**：🔀 改半方案、📅 上课日期、↩ 写回排课表、🗑 删除存档（管理员）。只读角色没有「更多」，上课日期直接摊开。

## 草稿／定版与旧版

- **存档＝草稿**。状态列标「📝 草稿」，下面一条橘色说明；主任看到的写「秘书处还在调整，内容可能还会改」。
- **按「✅ 定版」才是正式版**。状态列的标签写「✅ 已定版 · 定版人 时间」（不另外占一条）。能定版的人＝能存档的人。
- **定版后再存档 → 自动变回草稿**，要重新定版。所以主任不会把改到一半的东西当成正式课表。
- **列印抬头**会印「（草稿，未定版）」或「（定版 vN）」。
- **旧版**：每次存档（或删除存档）前，被盖掉的那一版会留下来，每学期留最近 5 个，在「⚙️ 选项 › 🕘 旧版」可以载入回来（载入只是放到画面上，按存档才会盖掉现在的）。

## 遵守的排课规则（摘要）

> 这里只列骨架。完整版 → `docs/课表制作_排课规则说明.md`，或系统里的「**ℹ️ 排课规则**」弹窗（所有角色都看得到）。

- **🔴 硬约束**（违反标红，必须解决）：容量够、一时段一教室一门课、老师不撞堂、届别不撞堂。
- **🟠 尽量做到**（做不到也照排）：两节不同天、两节同一间教室、少让个别学生撞课。原本的「软提醒／已核对」（学分≤21、上下半 4+3、老师每半≤4 门）2026-11-18 全部拿掉。
- **🟡 软优先**（尽量，冲突可让；系统的规则弹窗不列，只在规则说明文档里）：321/322 优先给 CD、LA/KH 层级先修低的、教室挑刚好够大。
- **⚙️ 特殊规则**：Capstone「周五 Capstone 日」（预设，可在选项关掉）：每门各一个框、各排 2 节，全部排周五上午＋下午；同一位老师的课同时间同教室（合班）；Capstone 之间届别重叠不算撞课（学生周五会被打乱分给各老师）；同老师固定教室（233–236）；修 Capstone 的届别与教 Capstone 的老师周五不排一般课；Capstone 不套「个别学生不挡排课」；一般课的个别学生（届别只 1 人）不挡排课；专用教室（电脑室）照排课要求；**排课要求**（指定教室／限定星期／连续两天）在排课表新增、编辑课程时用栏位填，旧备注的文字写法仍照办。
- **多个届别一起上同一门课**：一笔排课勾多个届别就是一门课、排一个时段，不需要另外标示（「合班」这个词与旧规则已于 2026-11-18 全站拿掉）。
- **📋 排课先后**：越难安排的越先排——届别越多先排、越抢手先排、Capstone 大班先排；试 48 种顺序，先比没排上的门数、再比只排 1 节的门数、最后才比其余扣分，取最好的一版。

## 谁能用

| 角色 | 能做什么 |
|---|---|
| **Head of Administration（秘书处）、管理员** | 排 / 微调 / 存档 / 定版 / 载入旧版 / 列印；后台的「教室库」「课表日期」 |
| **管理员** | 另可删除存档 |
| **主任（director）、其他** | 只读看 + 列印；看得到草稿（有标示）、未排课的原因与建议。主任另可透过撞课清单的「改 课码」去改排课表；排课表改了之后可按「🔍 试排预览」先看整张课表排不排得下（不存档、同事看不到） |

## 和排课表的关系（关键）

**排课表是来源，课表制作是据它排好、再存档的结果——排课表改了不会自动更新，但一定看得到。**

- **排课表那一页**：所选学期的课表存档跟排课表不一样时，筛选栏上方出现橘色「📋 课表制作还没跟上」横幅，可一键前往。
- **课表制作**：顶部橘色框逐门列出「课表是 X ／ 排课表是 Y」（课程／老师／届别／人数／上下半／备注，或新增、删除）。随时比对，不只看存档时。

要更新，由秘书处或管理员处理：

- **🅰 🧩 只补排**（推荐）：已排好的课留在原位（手动调过的也保留），只排**新增**的、原本没排上的、以及改了届别/人数后**原位放不下**的课；排课表删掉的课从课表拿掉。排完上方绿色框列出动了哪几门 → 核对 → 存档 → 定版。也可以自己从未排区把课拖进课表。
- **🅱 整张重排**：按「⚡ 整张重排」，以最新排课表重算整张，但**不保留**手动微调过的教室/时段。
- **老师、上下半**两边都能改 → 橘色框里逐门选「← 照排课表」或「写回排课表 →」，系统不替人决定方向。要全部照排课表，按「← 全部照排课表」（＝主任「试排预览」看到的结果）。

**主任这一边的流程**：改课时表单的「🗓 照现在的课表试排」逐门看 → 改完几门后到课表制作按「🔍 试排预览」看整张 → 按「✉ 通知秘书处」（站内消息，内容自动写好改了哪几门）→ 秘书处按「← 全部照排课表」→ 存档 → 定版。

## 几个人同时用

原则：**同一份存档，内容一样；角色只决定能按哪些按钮。**

- **别人存了新版或定版**：自己画面上方会出一行「🔔 … 载入最新」（每 90 秒看一次，不会自动换掉画面）。
- **存档前**：系统先看有没有人存过；有的话先警告，免得不知不觉盖掉别人的（被盖掉的在「🕘 旧版」）。
- **还没存档的改动**只有自己看得到，画面会写「同事看到的还是 vN」。
- **建议的内容大家一样**；只有「怎么操作」的说明（拖、点哪颗钮）只给能排课的人看。
- 各自不同、属正常的：两个选项（拆开两节同天、课排满优先）、面板开合、还原记录。

---

## 边界（不做什么 / 要人处理）

- **排不下的不硬塞**：留空标红、列进「待处理一览」，让人拖或调上下半（🔀 改半方案）。
- **不自动同步**：排课表改了不会自动重排课表；课表改了老师／上下半也不会自动写回排课表。
- **实习课不排进课表**（本来就不占教室时段）。
- **课表日期、教室库**由管理员或秘书处在后台设定。
- **人数超过教室容量**（排不进任何教室、或超过指定的教室）：建议里直接算「**拆成 N 班各约 M 人**」，由人拆班或换更大教室。
- **排课表的提示是按门数估的**，不是实际试排：门数够也可能凑不到共同空档（多届别的大课）。

## 四个选项（「⚙️ 选项 ▾」，默认都打勾）

| 选项 | 打勾时 | 记在哪 |
|---|---|---|
| **周五 Capstone 日** | Capstone 全部排周五上午＋下午；同一位老师的课同时间同教室（合班，画面叠成「整天一张卡」，不标红）；Capstone 之间届别重叠不算撞课。不打勾：Capstone 逐门排（先周五 → 周一～周四 → 周日） | 各自的浏览器 |
| **个别学生不挡排课** | 届别在一门课只有 1 人 → 不挡排课，撞到的列清单（Capstone 不适用） | 跟着存档走（两个人看同一份存档结果一样） |
| **拆开两节同天** | 同一门课两节同天时，多花几秒试着拆到不同天 | 各自的浏览器 |
| **课排满优先** | 宁可多几门同天／多几位学生撞课，也要把每门课两节排进去 | 各自的浏览器 |

## 系统内建的帮助（工具列「ℹ️ 说明 ▾」，所有角色可见；文字一律短条列）

- **🧭 使用引导** — 按两种身份编：**秘书处（Head of Administration）、管理员**（排、存、定版、列印，8 步）与**其他人（含主任）**（只读、列印，5 步，含主任改课三步）。两块内容人人一样，打开时自己那块排前面、标「你的身份」。**新同事先看这个。**
- **扣分的轻重（记在排课规则说明里）**：两节同一天 600 ＞ 备注「连续两天」没照办 200 ＞ 个别学生撞课每组 80 ＞ 两节不同教室 30（最轻，不是首要要求）；指定教室、指定星期是硬限制。
- **ℹ️ 排课规则** — 「一键自动排」按什么排：🔴 硬约束 / 🟠 尽量做到 / ⚙️ 特殊规则 / 📋 排课先后 / 🧮 多届别的课放哪一半，末尾附「排课表改了怎么更新（🅰/🅱）」。
- **🔧 瓶颈报告** — 没排上的课：从哪下手（调上下半／格子不够／拆班）＋逐门原因与建议。
- **💡 建议** — 待处理一览（没排上、只排 1 节、个别学生撞课）、课表检查（两节同一天、撞堂／超容量）、备注待看（没排到连续两天）各有「💡 建议」，给可操作的建议；课码、届别、老师可点，跳到排课表。
